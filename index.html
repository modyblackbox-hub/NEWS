GitHub Pages Static Deployment & Source Integrity

This dashboard is structured as a single-file static application ready for GitHub Pages (index.html). In production, a scheduled GitHub Actions workflow polls verified RSS/Atom XML feeds (NASA, arXiv, ScienceDaily, Phys.org, WHO, AP, Global Issues) and writes data/feed.json with exact UTC sync timestamps.

Verified Sources Referenced: World Health Organization (who.int), Associated Press (apnews.com), ISA Global Outlook (isa-world.com), Global Issues / IPS / UN News (globalissues.org), Reuters Institute 2026 Digital News Report (reutersinstitute.politics.ox.ac.uk), NASA RSS (nasa.gov), arXiv (info.arxiv.org), Phys.org (phys.org), ScienceDaily (sciencedaily.com), TikTok (@rachelc00k), and Pinterest Modeling Archive.
