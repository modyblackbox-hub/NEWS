Architecture Model

GitHub Pages Static-Feed Integration Blueprint

Zero-Backend · Scheduled Static Build

1. Scheduled RSS/ATOM Ingestion

A GitHub Actions cron workflow polls syndicated XML/ATOM endpoints on a 15-minute cadence: apnews.com, kjzz.org, nasa.gov/feed/, sciencedaily.com/rss/top/science.xml, phys.org/rss-feed/, and rss.arxiv.org/rss/cs.ai+q-bio.NC.

2. Intensity Scoring & Deduplication

Headlines are normalized into the four dashboard desks, scored into Critical/Breaking (active nationwide outages, airspace stops, geopolitical flashpoints), High Intensity (biosecurity, climate summits, leadership shifts), or Standard, and stamped with the exact UTC build time.

3. Static Bundle & Client State

The normalized payload is committed to data/feeds.json and deployed straight to GitHub Pages. Because static hosting serves pre-compiled HTML/JS with no server database, client bookmarks and filter preferences persist via lightweight runtime state.
